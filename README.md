# Patient Data Manager

A skill to collect, store & retrieve patient medical records from attached files.

## Download

Download the latest `.skill` file from the [Releases page](../../releases/latest).

## Features

- Store patient demographics & contact info
- Manage medical records & visit history  
- Track medications, dosages & schedules
- Store lab results with reference ranges
- Record vital signs with auto-calculated BMI
- Attach & extract data from PDFs, images, docs

## How to Use

1. Download the `.skill` file from [Releases](../../releases/latest)
2. Install it in your Kimi session
3. Attach patient files and say "Add this patient" or "Store this lab result"
4. Query stored data anytime: "What medications is Jane Doe taking?"
